# PathPilot AI — Database Schema Specification

**Database Engine:** PostgreSQL 15+ (Cloud SQL / Supabase)  
**Security Model:** Row-Level Security (RLS) enabled on all user tables  
**Primary Identifier:** UUID v4 (`gen_random_uuid()`)

---

## Detailed Table Specifications

### 1. `profiles`
Stores core user identity, preferences, gamification XP, and active subscription status.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | PRIMARY KEY, REFERENCES `auth.users(id)` ON DELETE CASCADE | Unique user identifier |
| `email` | `TEXT` | NOT NULL, UNIQUE | User primary email address |
| `full_name` | `TEXT` | DEFAULT '' | User display name |
| `avatar_url` | `TEXT` | DEFAULT NULL | Profile image storage URL |
| `current_role` | `TEXT` | DEFAULT 'Software Engineer' | Current job title |
| `target_role` | `TEXT` | DEFAULT 'Senior Solutions Architect' | Primary career objective |
| `xp_points` | `INTEGER` | DEFAULT 0 | Gamification points earned |
| `level` | `INTEGER` | DEFAULT 1 | Calculated user tier level |
| `streak_days` | `INTEGER` | DEFAULT 0 | Consecutive daily activity count |
| `created_at` | `TIMESTAMPTZ` | DEFAULT `now()` | Record creation timestamp |
| `updated_at` | `TIMESTAMPTZ` | DEFAULT `now()` | Record last update timestamp |

## Row Level Security (RLS) Policies

All user-owned tables enforce strict Row-Level Security policies in PostgreSQL.

```sql
-- Enable RLS on all user tables
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE resumes ENABLE ROW LEVEL SECURITY;
ALTER TABLE roadmaps ENABLE ROW LEVEL SECURITY;
ALTER TABLE applications ENABLE ROW LEVEL SECURITY;
ALTER TABLE tasks ENABLE ROW LEVEL SECURITY;
ALTER TABLE documents ENABLE ROW LEVEL SECURITY;

-- Profiles: Users can only view and update their own profile
CREATE POLICY "Profiles self access policy" ON profiles
  FOR ALL USING (auth.uid() = id);

-- Resumes: Users can only view, insert, update, delete their own resumes
CREATE POLICY "Resumes user isolation policy" ON resumes
  FOR ALL USING (auth.uid() = user_id);

-- Applications: Users can only view, insert, update, delete their own applications
CREATE POLICY "Applications user isolation policy" ON applications
  FOR ALL USING (auth.uid() = user_id);

-- Tasks: Users can only manage their own tasks
CREATE POLICY "Tasks user isolation policy" ON tasks
  FOR ALL USING (auth.uid() = user_id);

-- Documents: Users can only access their own vault documents
CREATE POLICY "Documents user isolation policy" ON documents
  FOR ALL USING (auth.uid() = user_id);
```

## Recommended Database Indexes

To guarantee sub-millisecond query performance across millions of rows, the following indexes are pre-configured:

```sql
CREATE INDEX idx_resumes_user_id ON resumes(user_id);
CREATE INDEX idx_roadmaps_user_id ON roadmaps(user_id);
CREATE INDEX idx_applications_user_status ON applications(user_id, status);
CREATE INDEX idx_tasks_user_completed ON tasks(user_id, completed);
CREATE INDEX idx_documents_user_type ON documents(user_id, type);
```
